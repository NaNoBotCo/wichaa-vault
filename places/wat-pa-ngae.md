# Wat Pa Ngae
*วัดป่าแงะ*

วัดป่าแงะ ตำบลแม่เจดีย์ อำเภอเวียงป่าเป้า จังหวัดเชียงราย เดิมที่ตั้งของวัดเป็นป่าเต็งที่ขึ้นตามธรรมชาติ (ทางภาคเหนือเรียกไม้ชนิดนี้ว่าไม้แงะ ) ชาวบ้านก็เลยเอาเป็นชื่อชองหมู่บ้านมาตราบเท่าทุกวันนี้ และได้จัดตั้งวัดขึ้นมาชื่อว่า
