# Wat Sri Suphan
*วัดศรีสุพรรณ*

วัดศรีสุพรรณ เป็นวัดราษฎร์สังกัดคณะสงฆ์ฝ่ายมหานิกาย ตั้งอยู่ในตำบลหายยา อำเภอเมืองเชียงใหม่ จังหวัดเชียงใหม่
